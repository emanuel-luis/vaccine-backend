| 4 | 2026-10-25 | Integration tests | Testcontainers 2 with `@ServiceConnection`; `*IT` classes run by failsafe in `mvn verify`, unit/slice tests by surefire | Real Postgres in tests; `make test-fast` stays Docker-free |

| 15 | 2026-10-25 | Source licenses | Record attribution and mark the exact terms as "to be confirmed" in the manifest and `docs/data-sources.md` | IBGE's terms page and the CNES portal license field could not be retrieved automatically; no license is claimed that was not verified |

| 17 | 2026-10-25 | Seeds schema | dbt seeds in schema `reference` | Keeps `staging` views-only |
| 18 | 2026-10-25 | Synthetic generator | Generated offline from the vendored snapshots and the schedule seed; per-state take-up of the first dose, fixed continuation for later doses; quarterly lots and receipts; window may not cross a CNES extract | Deterministic and testable without a database; coverage near realistic levels (Penta D3 about 82% at 200k rows); facts join the unit version valid on the dose date |
| 19 | 2026-10-25 | Coverage denominator | Censo 2022 population of the target age in the state, scaled by the run's `sample_fraction` | The official indicator uses live births (SINASC), not vendored here; the method is labelled in every row |
| 20 | 2026-10-25 | API data access | `JdbcClient` + Java records over the marts; JPA, Lombok and Mustache removed | dbt rebuilds mart tables, so the API should not validate or own their schema; plain SQL keeps the contract visible |
| 21 | 2026-10-25 | API shape | `/api/v1`, `{data, meta}` envelope with source and synthetic flag, required month range of at most 36 months for dose endpoints, problem details for errors, 503 while marts are missing | Bounded responses; consumers always see that the measures are synthetic |
| 22 | 2026-10-25 | Legacy API | Removed with its loaders and CSVs; Flyway `V5` drops the legacy tables | Replaced by the warehouse; the 2023 unit list is preserved as the vendored CNES snapshot |
| 23 | 2026-10-25 | Dependency scanning | OSV-Scanner on `pom.xml` and `elt/uv.lock` (weekly and on PRs) plus grouped weekly Dependabot | One scanner for both ecosystems, no API key needed |
| 24 | 2026-10-25 | Repository name | `emanuel-luis/vaccine-warehouse` (was `vaccine-backend`); Maven artifact, compose project and application name follow; GitHub redirects the old URL | The repo is now a dimensional warehouse, not a CRUD backend; owner's choice (program decision 21) |
| 25 | 2026-10-25 | Real-time design | Postgres speed layer (live landing + one incremental aggregate + NOTIFY); dbt stays the history | No broker for a single developer; transactional |
| 26 | 2026-10-25 | Live schemas | `raw.live_dose` landing, `live` aggregates, `app` campaigns; all Flyway | Keeps the layer split visible |
| 27 | 2026-10-25 | Batch watermark | Generation protocol (SHARE vs ROW EXCLUSIVE), closed by a dbt `on-run-start` hook on run/build, W carried by the fact | Exact with in-flight transactions |
| 28 | 2026-10-25 | Serving merge | `mart_doses_daily` + `live.dose_daily` above W, one statement | One grain, no double count during swaps |
| 29 | 2026-10-25 | Reconciliation | dbt test for absorption + `vaccine-elt reconcile` in REPEATABLE READ, results in ops | Build gate plus continuous evidence |
| 30 | 2026-10-25 | Ingest idempotency | `Idempotency-Key` per client; replay 200, mismatch 422, duplicate dose 409, 503 without marts | Follows the IETF draft; safe retries |
| 31 | 2026-10-25 | Clock in the live path | `administeredAt` from the client, a [-30 days, +5 min] window, `received_at` as metadata | Live data is inherently time-bound; checked only at validation |
| 32 | 2026-10-25 | SSE | fetch + bearer, LISTEN/NOTIFY per instance, 2 s ticks, resync instead of replay, closes at token expiry | No ticket store; correct by refetch |
| 33 | 2026-10-25 | Identity | Keycloak 26.8.1 dev mode, committed realm with env placeholders, browser-URL issuer, JWKS on the compose network | Reproducible, no secrets in git |
| 34 | 2026-10-25 | Roles and scope | 3 user roles + `dose-ingest`; `region_scope` claim; URL rules in one place; deny without scope | Small and auditable |
| 35 | 2026-10-25 | Small cells | k = 5 primary suppression in the API and exports, never in marts; secondary (complementary) suppression out of scope and documented | Marts stay reconcilable; data is synthetic |
| 36 | 2026-10-25 | Geometries | IBGE malhas v3 `minima` vendored through `fetch` with sha256; attribution recorded, license "to be confirmed" as in decision 15; no basemap tiles | Offline, no paid tile service |
| 37 | 2026-10-25 | Jobs | `ops.job` queue + single-active index + SKIP LOCKED Python worker; host targets kept (amends 12) | Reuses ELT code; CI unchanged |
| 38 | 2026-10-25 | dbt results | `run_results.json` -> `ops.dbt_invocation` / `ops.dbt_node_result` | The API reads ops only |
| 39 | 2026-10-25 | Manifest to UI | `load-reference` records entries in `ops.load_run_source`; optional `license_status` | No file access from the API |
| 40 | 2026-10-25 | OpenAPI | springdoc 3.1.1, committed spec, drift IT, openapi-typescript + openapi-fetch | Typed client, CI-checked |
| 41 | 2026-10-25 | Web pins | TypeScript 5.9.x, react-router library mode, own ECharts wrapper | Peer constraints; fewer dependencies |

| 43 | 2026-10-25 | Simulator | Python, generator inputs, one person per dose, stdlib HTTP | Valid by construction |
| 44 | 2026-10-25 | Campaigns and exports | `app.campaign` with optimistic locking; CSV `;`, UTF-8 BOM, decimal comma | Excel pt-BR users |
| 45 | 2026-10-25 | PR1 window | Ingest disabled unless `VACCINE_INGEST_ENABLED`; removed in PR2 (done: the endpoint needs the `dose-ingest` role) | No open write endpoint on main |
| 46 | 2026-10-25 | UI language | pt-BR UI text; code and docs stay English | Audience is SUS staff |
| 47 | 2026-10-25 | Resource-server starter | `spring-boot-starter-security-oauth2-resource-server` (+ `spring-boot-starter-security`; tests: `spring-boot-starter-security-test` and `...-oauth2-resource-server-test`) | The Boot 4 name found in the 4.1.2 BOM; the old `spring-boot-starter-oauth2-resource-server` is a deprecated alias |
| 48 | 2026-10-25 | UF codes | Static UF abbreviation to IBGE code table (first two digits of a municipality code) in `security/UfCodes`; scope claims naming an unknown state are invalid | Scope checks need no database lookup and cannot fail with the marts down |
| 49 | 2026-10-25 | Scope enforcement | `ScopeGuard` (static, on the token) returns the `RegionFilter` repositories use; no `region` means the caller's whole scope; wider or elsewhere is 403 `region_out_of_scope`; state-grain endpoints close to municipality callers; a unit history needs every version inside the scope | Deny by default; the existing batch endpoints keep their shape |
| 50 | 2026-10-25 | Realm hardening | `region_scope` is declared in the user profile, viewable and editable by admins only; `sslRequired` is `none` (local HTTP demo realm) | A user must never widen their own scope; the realm is for localhost only |
| 51 | 2026-10-25 | OpenAPI drift check | `OpenApiSpecIT` needs no database (Flyway off, LISTEN thread mocked); springdoc writes sorted keys; `make openapi` rewrites `docs/api/openapi.json` | The spec can be regenerated and checked anywhere without Docker |
| 52 | 2026-10-26 | Suppression scope (amends 35) | k = 5 applies to counts of 1 to 4 whose geography is a municipality or a health unit (map at municipality level, unit rows, and any breakdown, series or summary whose effective region is a municipality); national and state cells and zeros are never suppressed; coverage is decided on the numerator; one implementation, `dashboard/Suppression`, in the API and the exports only | Small cells are the re-identification risk; states are large enough, and hiding them would empty the national map |
| 53 | 2026-10-26 | CSV export format | `GET /api/v1/exports/{dataset}` for gestor only: `text/csv; charset=UTF-8` with BOM, `;` separator, CRLF, decimal comma, English snake_case header, a `suppressed` column with the cell left empty, text cells that start with `=`, `+`, `-`, `@` prefixed with `'`, at most 200,000 rows (400 above) | Opens correctly in Excel pt-BR; spreadsheet formula injection is closed; bounded memory |
| 54 | 2026-10-26 | Campaign locking | `app.campaign.version` is the optimistic lock: `ETag` is the quoted version, `PUT` and `DELETE` need `If-Match` (428 `if_match_required` when missing, 412 `version_mismatch` when stale or not one of our tags), the update is one `UPDATE ... WHERE campaign_id AND version RETURNING`; campaigns outside the caller's scope answer 404 on read, update and delete; a body region outside the scope is 403 `region_out_of_scope`; `created_by` is the token `preferred_username`, else `sub` | No lost updates without row locks; no existence leak across regions |
| 55 | 2026-10-26 | Coverage goals | `coverage_goal_pct` and `goal_source` in the schedule seed and `dim_vaccine`: 90 for BCG and rotavirus, 95 for the other indicator doses. Source status: to be confirmed (`docs/data-sources.md`), like the licenses of decision 15 | The alerts need a goal per dose; the repository cannot fetch the gov.br pages to cite one, so the status is explicit |
| 56 | 2026-10-26 | Low-coverage alerts | `GET /api/v1/alerts/low-coverage` reuses the map's coverage (merged doses of the year with `age_band_years <= target age` over the expected population) in one statement for every indicator dose. Areas below the goal (compared on the 1-decimal coverage), without suppressed cells (decision 52) and without population, by gap descending, at most 200 | Same numbers as the map; hiding small cells keeps the list as safe as the map |
| 57 | 2026-10-26 | Simulator behaviour | Draws from the vendored snapshots and the schedule seed, one new synthetic person per dose, `administeredAt` = now; a fresh `Idempotency-Key` per dose, reused on retries; backoff 1-30 s; 401 refreshes the token; random seed by default (a fixed seed would collide with its own earlier doses after a restart, 409); heartbeat file every 10 s, compose healthcheck fails after 30 s | Valid by construction and safe to restart; extends decision 43 |
| 58 | 2026-10-26 | Job queue API | `POST /api/v1/admin/jobs` inserts a `queued` row in `ops.job` and sends `NOTIFY job_queued` in the same transaction; the partial unique index `ux_job_single_active` allows one queued or running job, and its violation is answered 409 `job_already_active`; 202 with `Location` | The database enforces one job at a time, so two admins cannot race; the worker wakes without polling |
| 59 | 2026-10-26 | Worker owns job status | The API only inserts `queued` rows; the worker alone moves a job to `running`, `succeeded` or `failed`, writes `ops.job_log` and announces lines and status changes on `job_event`; the hub relays them as SSE `job` events to data-admin subscribers only (role stored per subscriber at subscribe time) | One writer per state machine; job logs never reach other roles |
| 60 | 2026-10-26 | Admin endpoints and dbt results | `/api/v1/admin/**` is data-admin only through explicit URL rules (an unlisted admin path stays denied); dbt `run_results.json` is copied into `ops.dbt_invocation` and `ops.dbt_node_result`, and the API reads only those tables | No file access from the API; same deny-by-default rule as the other endpoints |
| 61 | 2026-10-27 | Node base image majors | Dependabot ignores major versions of the `node` image in `web/Dockerfile`; minor and patch updates of the 24 line still come. Node 24 is in maintenance until its end of life on 2028-04-30 (github.com/nodejs/Release), so the move to 26 LTS is due before then |
| 62 | 2026-10-27 | TypeScript majors | Dependabot ignores `typescript` majors in `web/`; PR #14 (5.9.3 to 7.0.2) was closed because `npm ci` fails with ERESOLVE | Keeps decision 41. | 63 | 2026-10-27 | Diagrams as code | D2 v0.9.0 pinned in the Makefile with the sha256 of its Linux release, ELK layout, theme 0 with dark theme 200, `--scale 1`; sources and rendered SVGs side by side in `docs/diagrams`, rendered through WSL or CI with the Linux binary; CI job `diagrams` runs `make diagrams-check` and is a required check on main | Program decision 32; the same version, style file and targets as the pilot repo. | 64 | 2026-10-27 | Makefile strict mode | The diagram recipes start with `set -euo pipefail`; the Makefile keeps no global `.SHELLFLAGS` (the pilot sets one) | `dbt-build` has to keep going after a failing `dbt build` to record its results, which a global `-e` would stop |
| 65 | 2026-10-27 | Diagram set | 11 diagrams: architecture; data flow split into batch and live; four user flows (live dashboard, campaign, data job, simulator); four ERDs (star schema, speed layer, load runs, jobs).
